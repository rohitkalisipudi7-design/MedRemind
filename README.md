# MedRemind
Medication Reminder &amp; Inventory App 
App Overview: Description of the native Android medication reminder and adherence tracker app.
Core Features:
🔔 High-Priority Alarms & Loud Ringtones (AlarmManager.setAlarmClock, full-screen lock-wake screen, continuous ringtone audio).
🕒 Multiple Doses Per Single Day (1x, 2x, 3x, 4x presets + custom dose times with individual tracking).
📅 Flexible Frequency & Calendar Date Picker (Everyday, Alternate Days, Specific Weekdays, and Interactive multi-date month picker).
📦 Inventory Vault & Low Supply Alerts (Auto-deduction on intake, restock options).
📊 Clinical Ledger & Monthly Compliance Matrix (Adherence scorecards, daily compliance heatmap).
Tech Stack & Architecture: Kotlin, Jetpack Compose (Material 3), Coroutines/StateFlow, Alarm Broadcasts.
Installation & Sharing Guide: Instructions for sharing and installing the .apk on any device without USB debugging.
